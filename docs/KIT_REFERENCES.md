# Home kit references
Reference date: 1 October 2026.

This build implements twelve country selections and distinct home-strip palettes and patterns. Shirt patterns are original procedural recreations based on the official references below. The small chest shields are country-code placeholders, not finished federation crests. The current build therefore does **not** claim to contain exact official kits. Federation badges and detailed matching against front/back product photographs remain an asset task.
